# kazaia-media

Visuels des réseaux sociaux de Kazaia (Instagram, TikTok, Facebook), servis par GitHub Pages pour Metricool.

- `media/` : fichiers publiés (MP4 des reels, PNG des carrousels).
- `outils/` : charte, polices, scripts de rendu et pages de chaque semaine (voir `outils/LISEZMOI.md`).

Aucune donnée de foyer ni de client. Kazaia · kazaia.fr
